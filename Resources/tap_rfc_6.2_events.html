6.2 Event Categories

6.2.1 ROOM Events

Event TypeFormatDescription
PRESENCE ENTEREVT ROOM PRESENCE ENTER <username>Player entered current room
PRESENCE LEAVEEVT ROOM PRESENCE LEAVE <username>Player left current room
CHATEVT ROOM CHAT <username> <message>Room-scoped chat message

6.2.2 GLOBAL Events

Event TypeFormatDescription
CHATEVT GLOBAL CHAT <username> <message>Server-wide chat message

6.2.3 GROUP Events

Event TypeFormatDescription
INVITEEVT GROUP INVITE <leader>Group invitation received
JOINEVT GROUP JOIN <username>Player joined group
LEAVEEVT GROUP LEAVE <username>Player left group
CHATEVT GROUP CHAT <username> <message>Group-scoped chat message

6.2.4 STATS Events

Event TypeFormatDescription
